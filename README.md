# Church Band Score

Single-file web app for church band drum charts.

## Open the app

**GitHub Pages (enable once):**  
https://laanwong.github.io/church-band-score/

1. Go to https://github.com/laanwong/church-band-score/settings/pages  
2. Source: **Deploy from a branch** → Branch **main** → folder **/ (root)** → Save  
3. Wait ~1 minute, then open the link above on your phone / iPad / laptop.

**Or** download `index.html` and open it in Safari / Chrome.

## Features

- YouTube reference track
- Section arrangement (Verse, Chorus, fills…)
- Lyric + real drum notation (VexFlow)
- 8th / 16th resolution
- Groove presets + fill presets to pick
- Playback preview (▶ Play)
- Upload piano / other instrument scores as reference
- Edit mode + Display mode for the team on stage
- Auto-save in browser + Export / Import JSON to share
